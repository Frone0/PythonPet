# PythonPet
A simple console app where you need to take care of a pet and can play games with it

# Features
   - pet stats

   - feeding the pet

   - 3 games

   - saving and loading

## Games
  There are 3 games

  ### Guess the number

  ### Cities game

  ### RealOrFake
  And the best one: it is a game where a little bigram model
  makes names, and you should guess whether it is a real city or not.

  The model was trained on 32,000 names of cities.

## How to run

  - Python version - 3.15
  - Windows (there are some libraries that only work on it)

  - Start the game from: mainStarter.py




The city names dataset was taken from GeoNames (geonames.org)
